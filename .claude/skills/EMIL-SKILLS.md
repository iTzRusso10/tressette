# Skill di Emil Kowalski (design e animazioni)

Skill copiate da https://github.com/emilkowalski/skills
(commit a81dbca del 28 ottobre 2026, licenza MIT © 2026 Emil Kowalski, vedi `EMIL-SKILLS-LICENSE`).

Le 16 skill stanno in `.claude/skills/`, accanto a quelle di Addy Osmani.

Per questa app (React Native con Expo) contano soprattutto:

- `animate-expo`: animazioni con Reanimated, Gesture Handler, Expo Router ed expo-haptics; gesti, pannelli, transizioni, feedback al tocco.
- `emil-design-eng`: la skill principale, cura dei dettagli, componenti e decisioni sulle animazioni.
- `apple-design`: principi di design e movimento fluido di Apple (molle, gesti, materiali, tipografia, movimento ridotto).
- `review-animations`, `improve-animations`, `find-animation-opportunities`, `remove-animations`: rivedere, migliorare, trovare o togliere animazioni.
- `break-ui`: mettere alla prova una schermata con i dati peggiori (nomi lunghissimi, numeri enormi, liste vuote).
- `mobile-native`: per il sito (Expo web) sul telefono, perché sembri un'app e non un sito.

Le altre sono pensate per il web o per altro: `animate` e `animation-performance` (animazioni web, utili per il sito),
`animation-vocabulary` (i nomi giusti degli effetti), `pick-ui-library` e `prototype` (solo se richiamate a mano),
`ask-sonner` (libreria di toast per React web), `write-swift` (Swift).

Per aggiornarle: riclonare il repo e ricopiare le cartelle di `skills/`.
